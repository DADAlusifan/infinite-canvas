## Notes

- The web application stores projects, assets, and API keys in the browser; configured APIs are accessed from the frontend. WebDAV synchronization is optional.
- The Windows desktop implementation uses a selected local data directory, SQLite and indexed media files, with an embedded request proxy. Complete backup import is explicit; desktop runtime acceptance remains pending.
